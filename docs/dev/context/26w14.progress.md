## Highlights

- **TUI client shipped (PR #28):** Added a full Rust TUI client (`client/`) with AES-256-GCM inner payload decryption, WAL-mode SQLite persistence, and 46 tests — the largest single addition of the week (~2,600 lines).

- **End-to-end decrypt pipeline confirmed on live hardware:** The full chain from firmware BLE advertisement through gateway ingestion to TUI client decryption was validated against a real device, closing the loop on the v0.1 encrypted event path.

- **Firmware timestamp fixes:** Replaced the incorrect `k_uptime_get_32() / 1000` scaling with `lima_rtc_timestamp_ms()` wall-clock reads for `POLL_TICK` and `PRESSURE_BREACH` events — sensor payloads now carry accurate RTC time.

- **Documentation and repo hygiene:** Added `CONTRIBUTING.md`, updated `README.md` with a full repo structure and highlights table, fixed a misleading comment in the client crypto path (`reconstruct_lf` / `event_type` AAD), and added a Makefile `archive` target.
